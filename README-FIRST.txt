Pomodoro Timer repository

1. Edit APP_SPEC.md when product behavior changes.
2. Edit src/index.template.html, not dist/index.html.
3. Run build-standalone.bat on Windows.
4. Run scripts\check-repository.ps1 before pushing.
5. Commit generated dist artifacts when your repository policy requires them.

The app is intentionally local-first, bilingual, light-only, and dependency-free.
